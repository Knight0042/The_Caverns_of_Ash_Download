The Caverns of Ash is a 2D action adventure game where you fight past enemies to explore an extensive cave system. You can collect loot scattered around the cave in chests or you can take loot from enemies you have defeated. There is a full leveling system where you can exchange experience gained from turning enemies to ash into improved abilities. There is also a built in reset system in order to replay the game once you're done in the other settings menu. I also recommend switching the display to 1920x1080 if your display is big enough, as the graphics will be much better.

The most recent release contains full graphics and an added tutorial.
